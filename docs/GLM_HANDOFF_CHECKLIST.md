## 1. 当前状态：已有基础与尚未实现的边界

已有：5 个工作区；17 个课程节点与先修；教程/Notebook 链接校正；四步课程页；自动笔记草稿；阅读与最近步骤；资源收藏和搜索；PDF/视频本机预览及视频链接；2 个项目指南和 Markdown 报告；JSON 备份/迁移；4 个浏览器互动实验；11 项核心行为测试。

这些只是基础，不能视为完整教学平台：

- 多数课程只有短段落或通用专题指南，未形成完整课程、代码与验收题。
- Prompt 是固定规则演示，没有调用模型；RAG 是 4 份虚构资料的词项检索，没有 embedding 和生成；Agent 是固定状态机故障模拟；具身实验是无障碍、无噪声的二维变换演示。
- Agent 中间状态未持久化，刷新会重置；只有最终实验记录保存。
- 实验记录最多 100 条；能力统计把固定练习通过映射成 diagnosed/verified，尚无独立能力评价。explained/implemented 字段未形成完整采集流程。
- 两个项目是学习指南与报告框，不是已实现的真实业务助手和完整仿真策略项目。
- `experiments/inference.py` 提供真实小模型 CPU 推理代码，但只做过语法检查，未下载权重运行，依赖范围未锁定。
- 无账户、云同步、后端实验服务、真实 AI 助教与真实机器人训练。
- 最近验证：11 项 Node 测试通过；浏览器走查了检索反馈、Agent 核验恢复、坐标变换、草稿刷新和窄屏；并不等于全部功能、全部 Notebook 和完整系统已验收。
