# 测试与浏览器回归

更新日期：2026-11-18。

## 分层

| 层 | 命令 | 覆盖 |
| --- | --- | --- |
| 源码语法 | `npm run check` | 前端模块、Node 入口与后端模块 |
| 核心与 API | `npm test` | schema/迁移、保存语义、历史分页、项目证据、实验引擎、API、账户隔离与同步冲突 |
| Python 语法 | `npm run pycheck` | 实验脚本可解析 |
| 发布元数据 | `npm run build:site && npm run verify:release` | `dist/` 内容版本、提交、入口和发布边界 |
| 浏览器 E2E | `npm run e2e` | 静态主链路、失败恢复、窄屏、生产构建、完整模式任务失败与同步冲突 |

首次运行浏览器测试：

```sh
npm install
npx playwright install chromium
npm run e2e
```

只跑不依赖后端的路径：`npm run e2e:static`。

## Playwright 环境隔离

`playwright.config.js` 启动三个独立服务：

| 项目 | 地址 | 说明 |
| --- | --- | --- |
| `static` | `127.0.0.1:4173` | 直接加载仓库源码，使用浏览器规则实验 |
| `dist` | `127.0.0.1:4174` | 先构建 `dist/`，验证生产发布资源 |
| `full` | `127.0.0.1:8788` | 临时 Node 后端，数据目录为 `e2e/.tmp-data` |

每次完整模式启动前会清空 `e2e/.tmp-data`，不会读取或修改 `server/data/` 与真实账户。浏览器上下文默认独立，测试使用唯一用户名；同步冲突测试显式创建第二个上下文，模拟两台设备。

## 已覆盖路径

- 起点诊断 → 课程笔记与阅读 → Prompt 规则实验 → 项目显式关联 → 项目档案导出 → 完整备份导出/替换导入 → 刷新恢复。
- 模拟 `localStorage` 配额失败：不得显示“已保存”，内容保留，重试后写入。
- 损坏备份在预检阶段失败，现有笔记不变。
- Agent 写入超时 → 刷新 → 从检查点恢复 → 核验收尾 → 历史保留。
- 390px 窄屏无横向溢出，键盘可聚焦“跳转到内容”。
- 生产构建的 `release.json`、内容版本目录和离线笔记写入。
- 完整模式无训练数据时任务明确失败，不显示“训练完成”。
- 两个浏览器上下文产生同步 409，冲突 UI 可见并可合并。

## 不在自动套件中的验证

- 真实付费模型回答质量、真实 embedding 模型下载与大模型训练。
- 真实第二台物理设备、真实域名 DNS/证书。
- 所有外部 Notebook 与外部仓库内容正确性。
- 依赖真实硬件的机器人或 GPU 任务。

这些必须在交付记录中单列为“未验证”，不能用本套件替代。
