# 用户指南

## 第一次打开

1. `npm run dev` 后打开 http://127.0.0.1:8787。侧栏底部显示模式：
   - **完整模式**：全部功能（真实模型、embedding、训练任务、账户同步）。
   - **本地模式**：没有后端时的降级；课程、笔记、规则实验全部可用，真实调用入口会标注"需要本地后端"。
2. 首页会给出**一个准确的下一步任务**：预期成果、准备条件、预计时间（标注估计/实测）、继续入口。
3. 建议先花 2 分钟做[起点诊断](#起点诊断)（可跳过）。

## 学习主线

- **学习路线**：课程目录 + 全文搜索（课程/知识点/资料/章节）。任何课程都可以直接打开，不设强制解锁。
- **课程页**：固定四步——理解直觉 → 预测 → 修改任务 → 独立验证。每步含公式与维度、可运行代码与预期输出、常见错误。侧栏可展开**三层深度**（直觉/工程/研究）。
- **学习地图**：先修关系、后续用途、当前位置、已学/待补；实验通过的课程会换色。
- **继续学习**：恢复的是你上次真实的课程步骤位置，不是"第一个没打卡的模块"。

## 四个实验室

| 实验室 | 入门（规则） | 真实模式 |
| --- | --- | --- |
| Prompt 对照 | 固定规则演示变量 | 真实模型 4 变体对照、批量评测（含未见样例） |
| RAG 诊断 | 浏览器词项检索 | 本地 embedding（bge-small-zh）+ 自选语料 + 可选生成 + 引用 ID 检查 + 故障注入 + gold-evidence |
| Agent 故障 | 确定性工具模拟器 | 检查点持久化：刷新后可从检查点恢复，恢复前必须核验 |
| 空间与动作 | 2D 运动学 + 故障注入 | 浏览器触发真实任务：轨迹采集 → BC 训练 → 闭环评测；Q-learning 基础 |

使用纪律：**先做预测，再运行**；单次输出不构成结论；未见样例才算泛化。

## 能力评价

- 每门核心课底部有评价题（解释/代码修改/陌生故障/回归/未见样例），按量规自评或让助教点评。
- 五种状态分开记录：已阅读 / 自报完成 / 练习通过 / 实验通过 / 人工复核。答对一题不会再同时给"诊断+验证"。
- "能力评价"页显示每类能力的量规、覆盖课程与你的作答历史。

## 笔记与资料

- 笔记独立成篇，支持标签、Markdown、版本历史（最近 10 版可恢复）、课程/实验关联。
- 资料库可按类型（平台课程/外部/我的文件）、方向、难度、收藏筛选。
- 本机 PDF/视频不上传；页码/时间戳锚点保存在本地，重新打开需重新选择文件（浏览器权限限制）。

## 备份与同步

- **导出备份**：侧栏一键导出 JSON（含归档与旧版原始数据）。
- **导入**：先预检（范围/冲突/迁移来源），替换或合并可选；先写入本机恢复备份，成功后下载导入前数据。
- **账户同步**：设置页注册（本地后端，scrypt 加盐）；推送/拉取按版本号；冲突时可选合并/覆盖/下载。第二台设备：同一局域网运行后端（`AI_LEARNING_HOST=0.0.0.0`）或各自本地部署。
- **RAG 引用**：界面检查回答引用的 ID 是否存在于实际上下文，并展示上下文供核对；这不代表自动验证了事实支持，请逐条阅读原文。
- **局域网访问**：将后端绑定到 `0.0.0.0` 后，模型调用、RAG、实验任务和同步均要求登录账户。

## 项目空间

两个项目空间（资料助手 / 机器人走位）各有 4 个阶段任务、逐级提示、验收标准和方向侧重（产品/工程/研究），并可关联运行记录导出 Markdown。它们是教学脚手架和实验链路，不是已经完成独立交付验收的完整业务项目。论文复现模板见 `docs/REPRO_EXAMPLE.md`。

## 数据安全

- 模型密钥只在服务器环境变量；前端无法读取。
- 本机 PDF/视频不会发送到模型服务。账户同步会把学习数据发到你配置的本地后端；RAG 生成会把所选检索片段发给当前模型提供商。
- 模型调用显示 token 用量与费用估算（估算常数公开标注）。
